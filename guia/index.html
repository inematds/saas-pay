Cobrar com Asaas e logar sem senha, sem reinventar os dois

PIX, cartão à vista, cartão parcelado e boleto via Asaas — com liberação de acesso automática pelo webhook — mais login por magic link (Supabase), prontos pra copiar pro seu SaaS. Documenta os erros sutis que custam horas: idempotência, PKCE, valor em centavos vs reais.

O que é

Não é uma lib pra instalar — é um guia pra copiar

Extraído de produção (pay.inema.pro, inema.pro, inemaonline), sem chaves nem dados reais. TypeScript funcional em examples/, pronto pra você adaptar nomes de tabela e colar no seu projeto.

💰 PIX, cartão e parcelado

Cliente mínimo da API Asaas: customer, payment com billingType (PIX/CREDIT_CARD/BOLETO), parcelamento via installmentCount/totalValue, e QR Code do PIX.

🔔 Webhook idempotente

Rota completa com auth em tempo constante, dedup por paymentId, e a regra de quando responder 200 vs 500 pra não brigar com o retry do Asaas.

🔑 Magic link sem PKCE

Login sem senha via Supabase Admin API — documenta o bug clássico de usar action_link hospedado (quebra por falta de code_verifier) e como evitar com verifyOtp.

Como funciona

Do clique em "assinar" até o acesso liberado

O dado de cartão nunca passa pelo seu servidor — o Asaas hospeda o checkout (Link de Pagamento) ou você cria a cobrança via API e redireciona pro invoiceUrl.

Cliente paga (PIX/cartão/boleto)→ Asaas hospeda o checkout→ Webhook confirma pagamento→ Calcula vencimento→ Grava assinante→ Email c/ magic link

Guia de uso · passo a passo

Do clone até o pagamento liberando acesso

Os arquivos de examples/ são o ponto de partida — copie, troque nomes de tabela pelo seu schema, e siga a ordem abaixo.

1

Clone o guia e leia o README

Toda a referência de conceitos (customer/payment/webhook, as duas formas de vender, cálculo de vencimento, magic link) está documentada lá antes do código.

git clone https://github.com/inematds/saas-pay
cd saas-pay # leia o README.md
2

Configure o Asaas

Painel → Integrações → Chave de API (guarde como ASAAS_API_KEY). Painel → Webhooks → nova URL https://seudominio.com/api/asaas/webhook, eventos PAYMENT_CONFIRMED e PAYMENT_RECEIVED, e um token de autenticação (guarde como ASAAS_WEBHOOK_SECRET).

# opcional: um Link de Pagamento por plano, pra vender sem nenhum código
Painel Asaas → Cobranças → Link de Pagamento
3

Copie o cliente Asaas e a rota de webhook

examples/asaas-client.ts tem customer, payment (PIX/cartão/parcelado/boleto) e QR Code do PIX. examples/webhook-route.ts já traz auth em tempo constante e a idempotência — só plugue suas funções de banco.

cp examples/asaas-client.ts examples/webhook-route.ts examples/vencimento.ts seu-projeto/lib/
4

Configure o Supabase e copie o magic link

examples/magic-link.ts gera o link certo (sem cair no bug do PKCE); examples/auth-callback.ts é a rota que consome os dois fluxos possíveis (OAuth normal e magic link gerado no servidor).

cp examples/magic-link.ts seu-projeto/lib/
cp examples/auth-callback.ts seu-projeto/app/auth/callback/route.ts
5

Teste em sandbox, ponta a ponta

Chave Asaas sem prefixo $aact_prod/$aact_M = sandbox automaticamente. Pague um PIX de teste e confira: webhook recebido → assinante gravado → email com magic link → login funcionando.

# só depois de validar em sandbox, troque pra chave de produção
ASAAS_API_KEY=$aact_prod_...
6

Quer um starter que já roda sozinho?

Hoje o repo é guia + trechos pra copiar. Um app Next.js completo (com modo mock de pagamento e banco local, pra rodar sem nenhuma conta configurada) está planejado — ver TODO.md no repo.
